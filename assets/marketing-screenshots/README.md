## How to Re-generate or Extend

To re-crawl the live application and refresh these images at any time:

```bash
# Re-run full desktop + mobile suite
npx playwright test e2e/marketing-capture.spec.ts --project=chromium

# Re-run only mobile studio captures
npx playwright test e2e/marketing-capture.spec.ts -g "Mobile Views" --project=chromium
```

Spec definition is maintained in [`e2e/marketing-capture.spec.ts`](file:///Volumes/X%20SSD%202025/Users/narrowchannel/Desktop/indii-music-founder/e2e/marketing-capture.spec.ts).
