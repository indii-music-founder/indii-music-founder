# Acceptable Use Policy (POL-013)

## 1. Purpose
This policy sets expectations for personnel, contractors, and authorized developers using indii.music computing assets, cloud consoles, code repositories, and network resources.

## 2. Workstation Security Baseline
Any device used to access production systems or write code for indii.music must comply with:
- **Full Disk Encryption**: FileVault (macOS) or BitLocker (Windows) enabled.
- **Screen Lock**: Configured to lock automatically after no more than 10 minutes of inactivity.
- **OS & Software Updates**: Automatic security patching enabled.
- **Endpoint Protection**: Native OS security features (macOS Gatekeeper/XProtect) enabled.
- **No Shared Credentials**: Password manager used for all accounts; passwords never reused.

## 3. Prohibited Activities
- Storing unencrypted customer data, secrets, or unreleased artist tracks on personal local storage outside designated project workflows.
- Disabling security monitoring, linters, or branch protection settings without written founder approval.
- Connecting unauthorized IoT or compromised hardware to corporate development networks.
