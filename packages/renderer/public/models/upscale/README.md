# Bundled super-resolution weights

Unmodified x2 and x4 ESRGAN Slim model files from the official npm package
`@upscalerjs/esrgan-slim@1.0.0` (MIT; included LICENSE).
Documentation: https://upscalerjs.com/models/available/upscaling/esrgan-slim/

These files are served from the application's own origin. No remote model CDN,
generation request, subscription quota, or source-artwork transmission is needed
for browser enlargement. TensorFlow.js and UpscalerJS run tiled inference locally.
