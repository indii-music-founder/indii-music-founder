INDII THESIS SOUNDTRACK

CURRENT TRACK: "What To Come" (techno, ~116 BPM four-on-the-floor)

`indii-thesis-theme.mp3` is a web-optimized transcode of the founder's
`archive/Music/What To Come.wav` (original: 48 kHz stereo WAV, 131 s).
Encoding: 48 kHz stereo, 192 kbps MP3 (~3.1 MB).

Facts from analysis of the original:
- Dominant sub-bass onset interval: ~515 ms → steady kick on every beat at
  ~116 BPM (four-on-the-floor), dense syncopated percussion between kicks.
- Loop point: the track ends loud and restarts with its quiet intro — no
  click at the join (measured sample jump 0.018), just a level drop back to
  the intro on each loop. Fine for a placeholder-grade loop; a dedicated
  seamless loop can replace it later.
- The loop plays continuously in the thesis player and drives the
  audio-reactive system network (bass/mid/high bands).

REPLACING IT

Drop the final theme into this folder using one of these filenames (the
thesis player checks them in this order):

  indii-thesis-theme.mp3
  indii-thesis-theme.m4a
  indii-thesis-theme.wav

Recommended delivery:

  - MP3 or M4A for the website
  - 44.1 kHz or 48 kHz stereo
  - A clean loop or a long-form score
  - No important opening transient before 100 ms
  - Keep enough headroom for comfortable browser playback
