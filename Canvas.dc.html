Recommended Fixes

Phase 1: Token Consolidation

  1. Merge --sonic-* tokens into main CSS variable system
  2. Define --shadow-* tokens (sm, md, lg, xl)
  3. Create --backdrop-blur-* tokens
  4. Document all tokens in design-tokens.md

Phase 2: Component Refactoring

  1. Refactor Sidebar.tsx to use CSS variables for backgrounds
  2. Update card.tsx to use glass-panel pattern
  3. Apply --dept-color variants to all department-aware components
  4. Add guard rule to prevent hardcoded colors in future PRs

Phase 3: Quality Gates

  1. Implement guard-no-hardcoded-color.mjs ESLint rule
  2. Add security:frontend-api-boundary check to package.json
  3. Document design token usage in contribution guide
  4. Monthly design system health audits
