# indii.music Security Architecture & Operational Controls

This directory details the technical security controls, boundary definitions, threat models, access control registries, and testing workflows that implement our SOC 2 commitments.

## Structure
- `architecture/`: Production boundary diagram, Remote Relay security architecture, OAuth token isolation, and structured audit log specifications.
- `threat-models/`: STRIDE threat models for Remote Relay, Meta integrations, and Cloud Storage audio vaults.
- `access/`: RBAC matrix, privileged account registry, break-glass procedures, and quarterly review logs.
- `testing/`: Vulnerability management workflows, penetration testing rules of engagement, and security verification matrices.
