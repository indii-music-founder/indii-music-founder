# Model Usage Policy

The canonical policy is [the repository-root Model Usage Policy](../MODEL_POLICY.md).
Use that document for approved routing, model references, trained-specialty
boundaries, and migration acceptance. This page deliberately does not maintain a
second approved-model list.

The approved target remains Argon Conductor → Flash 3.8 intelligence → matching
trained-specialty workers until an explicit routing update is approved. Preserve
trained endpoints and independent Nano Banana, Pro image, video, and audio paths.

Hydrogen and Carbon are evaluation candidates following the November 2026 model
review. Request compatibility metadata does not add them to runtime allowlists,
change live defaults, or establish project access, pricing, or deployed behavior.
