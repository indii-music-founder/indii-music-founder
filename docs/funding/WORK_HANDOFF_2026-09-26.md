## Work execution protocol

For each application:

1. open the live form;
2. copy every question into a working checklist;
3. map each question to the canonical answer bank;
4. tailor only what the program actually asks;
5. verify every number against the source of truth;
6. preserve strict distinctions among implemented, live-verified, planned, and projected;
7. save drafts before final submission;
8. review the entire application once for contradictions;
9. submit only with founder approval when the platform action is consequential.
