# Keyboard Shortcuts

Quick reference for all keyboard shortcuts available in indii.

## Command Palette

Open the command palette to search for any command, navigate to modules, or access settings.

| Shortcut | Action |
|----------|--------|
| `Cmd+K` or `Ctrl+K` | Open/close command palette |
| `↑` `↓` | Navigate commands |
| `Enter` | Execute command |
| `Esc` | Close command palette |

## Feedback & Help

Submit bugs and feature requests, or access help documentation.

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+B` | Report a bug |
| `Ctrl+Shift+F` | Request a feature |
| `Cmd+K` → "Help & Keyboard Shortcuts" | View this guide |

### Via Command Palette

You can also access these via `Cmd+K`:

- Type "bug" → "Report a Bug"
- Type "feature" → "Request a Feature"
- Type "help" → "Help & Keyboard Shortcuts"

## Dialogs & Modals

| Shortcut | Action |
|----------|--------|
| `Esc` | Close current dialog or modal |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Cmd+K` → Search "creative" | Go to Creative Studio |
| `Cmd+K` → Search "files" | Go to File Manager |
| `Cmd+K` → Search "chat" | Go to Chat |
| `Cmd+K` → Search "settings" | Go to Settings |

## Application (When Implemented)

| Shortcut | Action |
|----------|--------|
| `Cmd+S` or `Ctrl+S` | Save current work |

## Tips

- **Fuzzy Search:** The command palette uses fuzzy search, so you don't need the exact command name:
  - Type "r" to find "Report a Bug"
  - Type "feat" to find "Request a Feature"
  - Type "dash" to find "Dashboard"

- **Power User Mode:** Once you know the direct shortcuts, use them instead of the command palette for faster access:
  - `Ctrl+Shift+B` is faster than `Cmd+K` → "bug"

- **Settings:** Most app preferences and additional keyboard shortcuts (if any) are available in Settings (`Cmd+K` → "Settings")

## Platform Notes

- **Mac:** Use `Cmd` instead of `Ctrl`
- **Windows/Linux:** Use `Ctrl` instead of `Cmd`
- **Browser-based (Web):** Both `Cmd` and `Ctrl` work on Mac; `Ctrl` works on Windows/Linux
