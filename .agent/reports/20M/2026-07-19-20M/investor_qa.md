# Investor Q&A index

Start with [live_answer_card.md](live_answer_card.md). For every other question, answer at two depths and use the same evidence baseline.

Be ready for: what works today; what is proprietary; how agents work; audio/upload identity; distribution boundary; rights/finance authority; configured versus collected revenue; $10 tier boundaries; founder obligations; margins/churn/CAC; moat; IP ownership; security/privacy; founder dependence; next three proofs; why buy instead of build; and how the path changes at $50M/$100M/$1B.

Truthful pattern when incomplete: “The capability is implemented in the current product. We have not yet credited it as externally accepted; the next proof is [artifact/test].”

## IP questions — use the live answer card and register

For each question, answer: **asset/posture → evidence today → restriction →
next proof and accountable owner**. The source of truth is
`docs/data-room/13_IP_ASSET_REGISTER.md`; the human/counsel/counterparty work
is in `docs/RELEASE_CHECKLIST.md`.

- What do you own today, and what is only a documented claim pending evidence?
- What belongs to the artist/customer and is therefore excluded from company-IP value?
- What is licensed, open-source, provider-controlled, or otherwise vendor-dependent?
- What exact assignment, licence, registry, agreement, artifact hash, or commit
  can I review today?
- What would make the platform hard to transfer: missing chain of title, domain
  control, licence/data permission, vendor account, rights consent, or key-person dependence?
- What did you create or improve since the last meeting, and did that change
  technical proof only or legal/commercial transferability too?
- Why does the asset support a cautious replacement/transferability range but
  not an asserted transaction price?

Close with one state: **evidence available for review**, **implemented but
legal/transfer evidence pending**, **licensed or vendor-dependent**,
**customer-controlled**, or **unknown pending diligence**.
