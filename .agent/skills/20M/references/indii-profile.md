## Vertical thesis

indii is intentionally music-specific. General tools may remain useful in another industry, but that is not the present customer job. Test the premium created by less setup, fewer integrations, reduced context switching, fewer rights/release errors, and better music-business outcomes. Portability is a boundary, not an automatic discount.
